# EmployeeWorkingHoursTracker
A Python OOP program that uses a class, constructor, and instance method to manage multiple employee objects and calculate their total working hours from daily hour lists.
<br>
Topics Covered:
<br>
1. Class and Object
2. Constructor (__init__)
3. Instance Attributes
4. Instance Method
5. List
6. Built-in sum() Function
7. f-string
8. Multiple Objects
